## CORE_LOOP

**宏观循环（一次「行程」，30–90 秒决策 + 1–3 分钟骑行）**

```
选择下一段路 → 骑行段（控速/避障/跃障/管体力/遇遭遇）
   → 抵达节点（补给·交易·修马具·听传闻·接委托·休息推进日程）
      → 抉择事件（后果写入旅志）
         → 速写/记录（见闻↑、图鉴↑）
            → 回到「选择下一段路」，直至绕环一周回到柳湾村 → 结局判定
```

**微观循环（骑行中，2–5 秒）**

```
读地形 → 选速度档（漫步/小跑/疾驰）→ 消耗体力 → 遇障碍 → 跃/绕/停
   → 反馈（羁绊 ±、体力 ±、马具耐久 ±、见闻 +）
```

**核心张力（三选二，永远不够用）**：`时间（日程）` × `马匹状态（体力/伤病）` × `物资（干草/水/银角）`
走险路＝快但风险高；走平道＝安全但费时费粮；原地休整＝恢复但日程流逝、季节推进。

## STORY

**前提**：柳湾村一个从未出过谷地的旅人，继承了父亲留下的老马「青骢」和一本残缺的《环洲风物记》。末页只有一句：**「绕一圈，你才知道家在哪儿。」**

**主线**：向西绕行环洲七带，补齐 21 段《风物记》缺页（每带 3 页）。
**暗线 1**：信使少女芸的同伴制图师在雪原失踪 → 揭露隐修者身份。
**暗线 2**：盗匪「断刀」本是守桥军官，因军令不公落草 → 可敌可友。
**主题**：世界不靠征服来认识，而靠抵达。

**关键抉择（示例，后果写入旅志并被 NPC 引用）**

| 事件 | 选项 A | 选项 B | 选项 C |
|---|---|---|---|
| 断刀拦路 | 交出银角（安全，声望 −1） | 冲阵反抗（负伤风险，得线索） | 招揽同行（需声望≥3★，解锁守望结局） |
| 野马群 | 捕捉（得新马，延误 2 天） | 放行（见闻 +5，羁绊 +8） | 跟随一天（隐藏奇遇：野王） |
| 雪原遇难商队 | 救人（物资 −40%，声望 +2，负罪 −） | 绕行（省 1 天，负罪 +3，见闻 −5） | — |
| 砚生的地图 | 如实归还（声望 +2） | 抄录一份（捷径解锁，砚生后期冷遇） | — |
| 终点柳湾村 | 留下 | 再启程 | 托付给学徒 |

**结局（5）**

| ID | 名称 | 触发条件（引擎按数组顺序取最后一个命中项） |
|---|---|---|
| E1 | 归乡 | 完成环游（默认结局）；见闻 < 240 |
| E2 | 远航 | 见闻 ≥300 且 羁绊 ≥95（解锁二周目「外环·远海诸岛」） |
| E3 | 传承 | 见闻 ≥240 且 声望 ≥8 |
| E4 | 守望 | 声望 ≥12 且 负疚 = 0 且 羁绊 ≥70 |
| E5 | 迷失 | 见闻 < 80 或 马匹死亡（软失败，不弹 Game Over） |

> 数值全部在 `src/data.json` 的 `endings[].condition` 里，引擎用一个安全的小表达式求值器解析，改门槛不用动代码。
