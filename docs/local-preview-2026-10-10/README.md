# 本地试玩与真实模型联调

2026-10-10。工作台测试地址为 `http://localhost:3000/`，仅在当前运行开发服务的电脑可用。

打开工作台点击「体验示例」，即可试玩手工预置的「苹果小果园」。接到 10 个苹果获胜，漏掉 3 个失败，支持方向键／A、D 和手机按住左右按钮，重新开始会清空计数。示例作为新本地文档打开，保留现有草稿，可修改源文件、保存到本机并下载 ZIP；不调用模型，也不需要登录或数据库。

## 本轮实现

- 独立能力状态端点只检查本地配置和浏览器路径，绕过登录与数据库，不返回凭据或服务地址。配置存在仍不等于真实服务连通。
- 工作台在配置缺失、查询失败、加载中或旧版响应时暂停对应在线入口，本地草稿、源码编辑、试玩与 ZIP 导出继续可用；登录目标校验先于 nonce 和 cookie 写入。
- 固定评测数据集先全量校验，再创建输出目录或调用服务。人工验收绑定具体 artifact hash、样本和需求契约；缺失、旧版、过期、非法或未填写完整的记录不计为合格。
- `--prepare-acceptance` 只写全部未填写的验收模板，不调用模型或浏览器，不覆盖已有记录。
- 预置游戏使用和生成结果相同的 artifact、离线打包与预览路径，内容明确标为手工示例；每次打开创建独立副本，避免修改污染后续示例。
- 预览默认样式先于游戏作者的 CSS，保留长页面的正常滚动。示例在较矮的桌面预览采用双列，在较矮的手机预览采用紧凑布局，使完整画布和开始／重开按钮同时可见。

## 示例玩法验证

`pnpm qa:example` 已在真实浏览器的桌面 960×640 和手机 390×844 视口通过。控制器仅观察画布像素与可见计数，用实际键盘和触控按住按钮移动篮子，没有注入游戏变量、修改得分或改写源文件。两个视口都实际接到 10 个苹果获胜、故意漏掉 3 个失败，并在胜负两次重开后归零；运行异常、网络请求和模型调用均为 0。浏览器 OS 沙箱开启，游戏仍位于仅允许脚本的 iframe 沙箱内。

报告绑定此次示例快照的 SHA-256，见 [report.json](example-game/report.json)；它验证这一预置示例，不代表其他生成游戏符合玩法要求。

修复短预览后已按新快照重跑：另有 848×348、330×430 两项布局检查，画布、开始／重开及左右控制按钮完整位于视口且可直接命中，滚动为 0。两项完整玩法场景使用真实坐标点击或触摸，不使用可能自动滚动的元素点击，胜负与重开仍全部通过。

本地全量测试 311 项通过、6 项跳过：4 项需要一次性 MySQL 测试库，2 项需要 Linux 进程环境。类型检查通过。这些环境相关用例由 [CI](https://github.com/hsiaozzz/fly/actions/workflows/ci.yml) 在 Linux 与临时 MySQL 里执行，最终结果以对应提交的工作流和上传产物为准。

两套工作台与项目网页回归也已通过，包括缺失／失败／旧版／加载中的能力状态、保留原草稿打开示例、预览内实际键盘与触控移动、仅修改标题保留其他文件、ZIP 逐字匹配实际快照以及刷新后恢复编辑。在线流程回归使用受控 API fixture，不能据此认定 OAuth、模型或外部存储已连通；本轮 UI 截图保存在 [ui/](ui/)。

新增的实际工作台布局回归验证作者设定的背景、高度与滚动方式仍生效，并检查桌面／手机／切回桌面后的画布及按钮完整落在 iframe 内，开始前不需要滚动。实际预览视口约 848×348 和 328×428，见 [workspace-layout-results.json](ui/workspace-layout-results.json)。该用例已接入 CI，避免自动化点击的隐式滚动掩盖布局缺陷。

生产依赖隔离检查已通过：临时副本没有 `.env` 和业务凭据，仅安装生产依赖，编译入口及 HTTP health 正常，16 项浏览器 QA、60 组输入对照结果符合预期。最后另用真实本地 `http://localhost:3000/` 页面测试，没有 API fixture：HTTP 200、工作台打开示例、开始游戏与 ZIP 下载通过，未捕获运行异常，没有生成请求或云写入，见 [live-preview.json](ui/live-preview.json)。这仍不是公网部署或真实模型生成联调。

## 真实模型结果

用户批准 3 项评测，总上限 100,000 tokens。本轮只执行一次真实生成程序，测试接苹果、五子棋和记忆翻牌；三个请求链路都返回 HTTP 401，没有生成可试玩产物，也没有模型游戏质量成绩。

按缺失有效 usage 的保守规则共记 29,967 tokens，其中接苹果 14,022、五子棋 2,400、翻牌 13,545。这不是供应商确认的实际用量或账单。原始凭据、服务地址及错误响应未写入报告；脱敏记录见 [real-model-attempt.json](real-model-attempt.json)。

后续真实生成需要配置有效的模型服务访问凭据。当前评测预算只约束一次程序运行；跨崩溃恢复的持久账本仍待实现，不能在失败后重新启用生成并把计数从零开始。原评测目录保留，后续检查只能离线复用已有产物。

## 当前限制

本机数据库和认证配置缺失，真实登录、云端保存、发布及外部对象存储仍未联调；没有操作业务数据库、上传外部对象或部署公网服务。代码回归和本地示例的通过不能代表真实模型生成已恢复。
